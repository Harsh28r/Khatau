# Landing page photos (feature-based)

Add these files under `frontend/public/images/` to show your own photos. If a file is missing, the page shows a **labeled placeholder** (no blank blocks).

| File | Section |
|------|--------|
| `hero.jpg` | Hero background |
| `our.jpg` | "Our place" banner |
| `food.jpg` | "Who we are" — our food |
| `party-birthday.jpg` | Party card: Birthday party |
| `party-kitty.jpg` | Party card: Kitty party |
| `party-buffet.jpg` | Party card: Buffet & events |
| `chaat.jpg` | Category: Bhelpuri & Chaat |
| `sandwich.jpg` | Category: Sandwiches |
| `beverage.jpg` | Category: Beverages |

Use `.jpg` or `.png`. When a file is missing, the section still shows a clear fallback (e.g. "Chaat", "Sandwich", "Our place") so nothing looks blank.
